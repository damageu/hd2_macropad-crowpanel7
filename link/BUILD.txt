HD2 Macropad Link v1.1
=======================

Windows tray app for the CrowPanel Advance 7.0 USB-serial link.
Protocol UART rate: 115200. Do not change that to the esptool flash baud.

The firmware side lives in the repository root, environment crowpanel-adv7.
See docs/crowpanel/README.md. Close this app before flashing the board.

Build (MinGW-w64, from this directory):

    x86_64-w64-mingw32-windres res.rc -O coff -o res.o
    x86_64-w64-mingw32-gcc -O2 -municode -mwindows hd2link.c res.o -o HD2MacropadLink-v1.1.exe -lsetupapi -lwinmm -static

Linux unit test (parser and scancode map only; no Windows APIs):

    gcc -Wall -Wextra -O2 -o test_core test_core.c && ./test_core

The previously tested executable was named HD2MacropadLink-v1.1.exe.
Its resource version was 1.0.0 because res.rc had not been bumped.
This tree's res.rc says 1.1.0 so a rebuild is identifiable.
A rebuild will not match the old executable's checksum.

Optional diagnostic log, off unless this registry value is set:

    reg add HKCU\Software\HD2MacropadLink /v Log /t REG_DWORD /d 1

The log is written under %LOCALAPPDATA%\HD2MacropadLink\link.log.
